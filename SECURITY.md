# Security Policy

## Supported version

Security fixes are applied to the current `main` branch. This is a prototype;
older commits and deployments are not supported.

## Reporting a vulnerability

Please report vulnerabilities privately through this repository's GitHub
Security Advisory **Report a vulnerability** form. Do not open a public issue
for suspected vulnerabilities, credentials, personal data, or exploit details.

Include the affected route or component, reproduction conditions, impact, and
any suggested remediation. You should receive an acknowledgement within seven
days. Please allow reasonable time for validation and remediation before public
disclosure.

Never include live credentials or third-party personal data in a report.
